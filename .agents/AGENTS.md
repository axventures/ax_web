
# Design System Rule
- When creating or modifying any sections, MUST include the exact design touch: topographic contour lines, sweeping dashed lines (DecorativeLines.tsx), and strict adherence to the brand color palette (var(--brand-blue), var(--text-main), etc) and typography.

# Typography & Punctuation Rule (Strict)
- NEVER use em dashes (—) or en dashes (–) anywhere in website copy, UI text, headings, metadata, titles, or code comments. Always use a standard normal hyphen/dash (-), a comma (,), a colon (:), or separate sentences instead.
